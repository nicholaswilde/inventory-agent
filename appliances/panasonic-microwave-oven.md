## Error Codes & Diagnostics

| Code | Meaning | Action |
|---|---|---|
| `LOCK (Child Safety Lock)` | Child Safety Lock activated | Press Stop/Reset button 3 times to deactivate. |
| `H00 / H97 / H98` | Power supply / Inverter / Magnetron circuit failure | Oven stops cooking. Unplug 10s and retry; if code returns, contact authorized service center. |
| `DEMO MODE / D` | Demo mode active (controls operate but no microwave cooking power) | Press Power Level button once, Start button 4 times, Stop/Reset button 4 times. |
