## Error Codes & Diagnostics

| Code | Meaning | Action |
|---|---|---|
| `Malfunction Indicator Lamp (Check Engine Light)` | Emissions control system issue or loose fuel cap | Check and tighten fuel cap; if light stays on, have vehicle inspected by dealer or service center. |
| `Low Oil Pressure Indicator` | Engine oil pressure critically low | Stop vehicle safely, turn off engine immediately, check oil level. Do not run engine with low oil pressure. |
| `Charging System Indicator` | Battery is not being charged by alternator | Turn off electrical accessories; pull over and have vehicle inspected immediately. |
| `Brake System Indicator` | Parking brake applied or brake fluid level critically low | Release parking brake; check brake fluid reservoir under hood for leaks or low level. |
| `Supplemental Restraint System (SRS) Indicator` | Airbag or automatic seatbelt pretensioner malfunction | Have SRS system inspected by authorized technician immediately. |
| `Anti-lock Brake System (ABS) Indicator` | ABS malfunction detected | Standard brakes work normally, but anti-lock function is disabled. Have ABS inspected. |
| `Immobilizer System Indicator` | Immobilizer key code not recognized | Use original programmed Honda ignition key; if blinking, car will not start. |
| `Maintenance Required Indicator` | Scheduled service interval reached (oil change / maintenance) | Perform scheduled service (oil/filter change) and reset indicator button. |
| `Door and Trunk Open Indicator` | Door or trunk lid not securely closed | Inspect and firmly close all doors and trunk lid. |
