## Error Codes & Diagnostics

| Code | Meaning | Action |
|---|---|---|
| `Low Battery (Flashing Battery Icon)` | Batteries are low; warning triggers after code entry | Replace all 4 AA alkaline batteries promptly. |
| `Critical Battery (Solid Battery Icon)` | Battery charge critical; electronic operation disabled | Unlock using physical backup key; replace with 4 fresh AA alkaline batteries. |
| `Wrong User Code ("X" Icon Flashes)` | Incorrect access code entered | Verify user code in Schlage/Apple Home app; wait for keypad lockout timeout if triggered. |
| `WiFi Connection Error (Flashing Comm Icon)` | Lock is searching or unable to connect to WiFi network | Check 2.4 GHz WiFi router status and distance; verify Apple HomeKit / home hub connection. |
| `Factory Default Reset` | Reset lock to factory settings and default access codes | Remove battery cover, disconnect battery pack, press and hold Inside Assembly button, reconnect battery pack, release button when LED flashes red and checkmark flashes green. |
